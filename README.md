# Geely Atlas Apps

Коллекция приложений для Geely Atlas FX11 G2, 2023 г. - н.в.

## Приложения

### LauncherWidgets
Виджет для размещения ярлыков приложений на главном экране.

**Скачать:** [LauncherWidgets-1.1.0.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/LW-1.1.0/LauncherWidgets-1.1.0.apk)

---

### QuickHV
Приложение предоставляет удобный интерфейс для управления обогревом и вентиляцией климат-контроля автомобиля Geely Atlas, включая подогрев сидений, вентиляцию, обогрев руля и другие функции.

**Скачать:** [QuickHV-1.3.7.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/QHV-1.3.7/QuickHV-1.3.7.apk)

---

### SeatSettings
Приложение позволяет управлять положением водительского и пассажирского сидений, а также 4 ячейки памяти для водительского сидения:

**Скачать:** [SeatSettings-1.1.5.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/SS-1.1.5/SeatSettings-1.1.5.apk)

---

### AtlasSettings
Расширенные настройки системы с поддержкой консоли

**Скачать:** [AtlasSettings-1.0.7.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/AS-1.0.7/AtlasSettings-1.0.7.apk)

---

### BootBox
Приложение для автоматического подключения Apple CarPlay / CarlinKit / CarPlay G-Box на головных устройствах Geely Atlas.

**Скачать:** [BootBox-1.0.2.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/BB-1.0.2/BootBox-1.0.2.apk)

---

### MusicWidget
Плавающий виджет для управления музыкой. Приложение отображает виджет на главном экране либо поверх других приложений, позволяя управлять воспроизведением музыки без переключения между приложениями.

**Скачать:** [MusicWidget-1.2.3.apk](https://github.com/Spywer/GeelyAtlasApps/releases/download/MW-1.2.3/MusicWidget-1.2.3.apk)

---

## Установка

1. Скачайте нужное приложение по ссылке выше
2. Установите APK файл на ваше устройство Geely Atlas
3. Следуйте инструкциям в приложении

## Требования

- Android система Geely Atlas
- Разрешение на установку из неизвестных источников
